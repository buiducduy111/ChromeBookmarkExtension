# Extension quản lý bookmark trên Chrome

## Mô tả tính năng
- Quản lý category (có icon tùy chỉnh có thể sử dụng fontawesome)
- Thêm / Sửa / Xóa Extension trong từng Category, riêng thêm cho phép nhấn nhanh vào biểu tượng Extension, icon bookmark là icon website
- Cho phép import toàn bộ Bookmark vào category "Tất cả"

## Yêu cầu
- Data extension lưu ở vị trí đảm bảo Chrome Sync được data
